            The rules live on chain

            Each agent answers to a NEAR contract it cannot overrule. The contract caps how many positions it may open per day and can be paused; only the owner can lift a pause or change the policy.

            The agent's key may call only record_decision and pause: it cannot move the contract's funds, deploy code, or change the policy. Exits are always accepted, so a pause or the cap never blocks a stop.

            Real money, real swaps

            Swaps signed by the agent's own key through NEAR Intents on mainnet, using the same code the live agent runs. Open the transactions on NearBlocks.
